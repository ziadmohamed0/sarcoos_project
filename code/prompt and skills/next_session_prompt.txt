## 2. NODE A: `esp32_sensor` (Sensor Node)

### Hardware
- MPU6050 IMU (I2C, SDA=GPIO21, SCL=GPIO22)
- NEO-7M GPS (UART2, RX=GPIO18, TX=GPIO19, 9600 baud)
- 4× HC-SR04 Ultrasonic (TRIG=25,27,12,32 / ECHO=26,14,13,33)

### Architecture
Singleton manager pattern — all sensor code inline in `SensorManager`. No separate HAL/MCAL layer.

### MQTT Publish (broker `192.168.1.4:1883`)
| Topic | Payload | Rate |
|-------|---------|------|
| `sarcus/sensors/imu` | `{"roll":N,"pitch":N,"yaw":N}` | 10 Hz (100 ms) |
| `sarcus/sensors/gps` | `{"fix":bool,"lat":N,"lon":N,"alt":N,"sats":N}` | 1 Hz (1000 ms) |
| `sarcus/sensors/ultrasonic` | `{"front":N,"back":N,"left":N,"right":N}` | 5 Hz (200 ms) |

### DSP Filters (added this session)

**IMU Complementary Filter (`readMPU6050()`):**
- Gyro bias calibration at init (200 samples, ~1 s)
- EMA low-pass on raw accel (alpha=0.15) to reject vibration
- `angle = 0.98 × (angle + gyro×dt) + 0.02 × accel_angle`
- Yaw integrated from gyro_z

**GPS Median Filter (`parseNMEA()`):**
- Ring buffer window=5 on lat/lon
- Bubble-sort median rejects single-sample coordinate spikes

| `main/inc/SensorManager.h` | SensorManager class + filter state members |
| `main/src/MqttManager.cpp` | MQTT publish for sensor data |

## 3. MODERN C++ CODING STANDARDS (both nodes)

1. **No `delay()` or `Arduino.h`** — use `vTaskDelay(pdMS_TO_TICKS(x))`
2. **Logging** — use `ESP_LOGI/LOGW/LOGE/LOGD(TAG, ...)`
3. **Thread safety** — shared state → `SemaphoreHandle` or `QueueHandle`
4. **MQTT payloads** — parse with `JsonParser` (Node B) or standard JSON (Node A)
5. **WiFi credentials** — always from NVS first, hardcoded fallback only
6. **No magic numbers** — constants in Kconfig or header defines
7. **C++17 allowed** — `if constexpr`, `std::function`, `constexpr`, `enum class`
8. **RTTI and exceptions are disabled** — no `dynamic_cast`, `typeid`, `try`/`catch`
9. **Const-correctness** — mark member functions `const` where applicable
